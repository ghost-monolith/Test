# VELVET LUXE — Classroom Demo

Изолированная учебная симуляция этапов фальшивой платёжной формы. Поля карты, срока действия, CVV и одноразового кода существуют только в браузере: сервер не принимает их, не хранит и не пересылает. Telegram получает только разрешённые события этапов, учебный ярлык студента и случайный ID сессии.

## Запуск локально

Требуется Node.js 20+.

```bash
npm install
npm start
```

Откройте `http://localhost:3000`.

## Telegram для проектора

1. Создайте отдельного учебного бота через BotFather.
2. Узнайте chat ID преподавателя/закрытой учебной группы.
3. Задайте переменные окружения `BOT_TOKEN` и `ADMIN_CHAT_ID` на сервере.
4. Запустите приложение. Бот отправляет только фиксированные уведомления о событиях.

Никогда не используйте токен личного или рабочего бота. Не добавляйте сбор содержимого платёжных полей.

## Развёртывание

Подходит Node.js web service (например, Render). Build command: `npm install`; Start command: `npm start`. Добавьте `BOT_TOKEN` и `ADMIN_CHAT_ID` в Environment. Это учебное приложение, не платёжный шлюз.

## Безопасность

- `/api/event` принимает только allowlist событий и ярлык студента.
- Не принимает `card_number`, `card_date`, `card_cvv`, `otp` или произвольный текст сообщения.
- В Telegram отправляются фиксированные шаблоны; пользовательские поля не включаются, кроме очищенного учебного ярлыка.
- Для аудитории используйте только вымышленные значения, выданные преподавателем.
