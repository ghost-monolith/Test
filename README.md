# VELVET LUXE — Demo Store

Демонстрационный интернет-магазин с 12 вымышленными товарами, корзиной и учебным оформлением заказа.

## Локальный запуск
Требуется Node.js 20+.
```bash
npm install
npm start
```
Откройте http://localhost:3000.

## Render
В репозитории есть Dockerfile. Создайте Docker Web Service и разверните последнюю версию ветки main.

## Ограничения демо
Реальная оплата, доставка, аккаунты покупателей и настоящие заказы не подключены. Не вводите платёжные реквизиты.
