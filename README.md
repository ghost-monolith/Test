# DARK GHOST — VELVET LUXE training simulator

Обновлённый демонстрационный каталог: 12 вымышленных товаров, категории, поиск, сортировка, цены со скидками, корзина и учебный checkout.

## Запуск
- Node.js 18+
- `npm install`
- `npm start`
- открыть `http://localhost:3000`

## Безопасность
Сервер принимает только псевдонимный ID, тип учебного события, канал SMS/PUSH-симуляции, результат и ID демонстрационного товара. Не добавляйте поля для реальных платёжных реквизитов, CVV, PIN, паролей, настоящих OTP, адресов плательщика или Track 1/Track 2. Не подключайте реальные платежи, SMS или push-аутентификацию. Используйте синтетические значения и согласованный университетом протокол с обязательным разбором после упражнения.

Telegram-интеграция пока не подключена; её можно добавить позже для безопасных событий и псевдонимных ID.
