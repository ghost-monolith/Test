# VELVET LUXE — Educational Demo Store

Премиальный демонстрационный магазин: каталог, фильтры, фотографии, корзина, отдельная страница учебной оплаты и уведомление администратора в Telegram.

## Запуск
Требуется Node.js 20+.

```bash
npm install
npm start
```

Откройте http://localhost:3000.

## Переменные окружения Render

Добавьте в Render → Web Service → Environment:

- `BOT_TOKEN` — токен отдельного Telegram-бота проекта VELVET LUXE.
- `ADMIN_CHAT_ID` — Telegram chat ID администратора.
- `TEST_CREDENTIALS` — JSON-массив искусственных тестовых значений, выданных преподавателем.

Пример структуры для учебного набора (замените значения на выданные куратором):

```json
[
  {
    "number": "SAMPLE-TEST-001",
    "expiry": "TEST-30",
    "cvv": "DEMO"
  }
]
```

Вставляйте JSON в одну строку в значение переменной Render. Это искусственные идентификаторы, а не банковские реквизиты. Не используйте настоящие номера карт, сроки действия или CVV.

## Как работает тестовая оплата

1. Сервер рассчитывает сумму из своего каталога и создаёт заказ.
2. Страница /payment принимает только учебные значения.
3. Сервер сравнивает все три значения с TEST_CREDENTIALS.
4. При точном совпадении заказ получает статус approved; при несовпадении — declined.
5. Telegram получает номер заказа, сумму, время и результат. Три тестовых значения включаются в уведомление только при точном совпадении с заранее заданным искусственным набором. Неуспешные введённые значения в Telegram не пересылаются.

Заказы хранятся в памяти процесса и могут исчезнуть при перезапуске/снапе Render. Это учебная версия, не production checkout.

## Ограничения

Реальные платежи, банковский эквайринг, доставка и база постоянных заказов не подключены. Никогда не вводите данные настоящей банковской карты.
